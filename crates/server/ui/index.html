This page is running on an in-browser simulation: a JavaScript port of the RiskANN algorithms (beam search, RobustPrune, Vamana insertion, exact search) behind the same HTTP API. Run the Rust server and open http://localhost:3000/ui to drive the real system with this same console. Timings shown in simulation are JavaScript timings, not RiskANN performance.

Explore the graph

Every dot is a stored vector and every line is a graph edge. Click anywhere to place a query, then watch the beam search walk from the entry point towards it. Approximate results are ringed in teal; the exact answer is dashed violet.

How the graph is built

Insert points one at a time and see each step of Vamana insertion: the beam search for the new point, RobustPrune choosing diverse neighbours, and reverse edges added to those neighbours. This view always runs the JavaScript port locally, with the same rules as the Rust engine.

Measure recall

Recall@k compares approximate results with the exact answer for many queries. Sweeping ef_search shows the trade-off: more exploration, higher recall, more work.

Setup

Queries are stored vectors with small random noise added. Latency is the server’s own search_duration_us.
